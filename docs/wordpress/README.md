# Page WordPress « Plantons + »

1. Créez une page WordPress nommée « Plantons + ».
2. Téléversez une capture ordinateur et une capture mobile dans la médiathèque.
3. Copiez le contenu de `plantons-plus-page.html` dans un bloc « HTML personnalisé ».
4. Remplacez `{{URL_CAPTURE_ORDINATEUR}}` et `{{URL_CAPTURE_MOBILE}}` par les URL des images téléversées.
5. Copiez le contenu de `plantons-plus-page.css` dans « Apparence > Personnaliser > CSS additionnel ».

Le logo est chargé depuis le dépôt GitHub de Plantons +. Si vous préférez l’héberger dans votre médiathèque WordPress, remplacez l’URL de l’image présente au début du fichier HTML.

Le texte et l’adresse e-mail de contact peuvent être adaptés directement dans le fichier HTML avant collage.
