# Logo officiel de reference

Le fichier `PNG/Plantons_reference_exacte.png` est le maitre visuel fourni et valide. Les exports PNG conservent exactement ce dessin, sans deformation. Les SVG encapsulent ce visuel pour garantir une apparence identique; ils ne sont pas des traces vectoriels natifs. Pour produire un SVG integralement vectoriel et strictement identique, fournir le fichier source Illustrator, Inkscape, Figma ou SVG d'origine.
